# SEHBS — sitio web v0.1

Primera versión navegable de **Sport, Exercise, Health & Biomedical Sciences — Weekly Research & Science News**.

## Abrir localmente
Abre `index.html` en un navegador. Para una vista más fiel, sirve la carpeta con un servidor local simple.

## Actualización semanal
La página principal obtiene la noticia destacada y las tarjetas de `data/articles.js`. Para una actualización semanal básica basta con editar ese archivo y reemplazar/agregar imágenes en `assets/`.

## Qué es demostración
Los textos de noticias son demostrativos. Antes de publicar en internet deben sustituirse por notas verificadas y enlazadas a sus fuentes originales.

## Publicación gratuita
Esta estructura es compatible con GitHub Pages, Cloudflare Pages, Netlify o Vercel. No requiere backend para la versión inicial.
